The first fast-drag attempt exposed a cursor-polling race. After replacing cursor polling with WPF event coordinates, the same real-input gesture succeeded. The final automated suite was rerun on the resulting binary: 52 passed, 0 failed.

The selection outline was visually checked in selection-outline.png, rendered through the production drawing code on synthetic content. The input tool completes a drag atomically, so this log does not claim a live screenshot while the mouse button was held.

This is a focused smoke test on the available desktop, not validation of all hardware, keyboard layouts, or monitor configurations. Other validation limits are listed in TEST-REPORT.md and README.md.
