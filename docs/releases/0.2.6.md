FrameForge 0.2.6 fixes three everyday Windows capture problems: the capture-folder button now opens File Explorer reliably, recent captures can be deleted with recovery, and completed captures bring the editor to the foreground.

## Downloads

- **FrameForge-Setup-0.2.6.exe** — recommended per-user installer with Start-menu shortcuts and an uninstaller. Upgrades preserve the capture library and preferences.
- **FrameForge-Portable-0.2.6.exe** — run without installing; the .NET runtime is included.
- **SHA256SUMS.txt** — checksums for both downloads.

Requires Windows 10 version 2004 or later, or Windows 11, x64. These executables are unsigned. Recording, trimming, and GIF export require a separately installed FFmpeg.

## Changes

- Open capture folder creates a visible Explorer window at the correct library path.
- Recent captures have a delete button and context-menu action. Files move to Deleted Captures; Undo delete restores them.
- Deleting the current capture clears the editor and stops autosave from recreating it.
- Captures restore and raise the editor while preserving its maximized layout and automatic clipboard copy.

## Validation

The Windows fix passed 79 application checks, including capture, clipboard, deletion/Undo, foreground restoration, scrolling, recording, and tray behavior. The packaged application passed 46 core checks and 13 installation, upgrade, and uninstall checks. Manual testing confirmed the final installed app opens the correct folder.

This release is the native Windows edition. The separate macOS/Linux desktop edition is a preview with its own downloads and remaining platform tests.
