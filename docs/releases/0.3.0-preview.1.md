FrameForge's first desktop preview provides macOS and Linux installers alongside the established Windows edition. This is **0.3.0-preview.1**, with no development-version increment.

## Choose your download

- **osx-arm64.dmg** — macOS 14 or later, Apple Silicon.
- **osx-x64.dmg** — macOS 14 or later, Intel.
- **linux-x64.deb** — Debian/Ubuntu, Intel or AMD 64-bit.
- **linux-arm64.deb** — Debian/Ubuntu, ARM64.
- Matching **tar.gz** files provide portable Mac/Linux bundles.
- **win-x64.zip** — experimental Windows desktop port. The native Windows 0.2.6 installer remains the recommended Windows app.
- **SHA256SUMS.txt** and **BUILD-INFO.json** identify the tested packages and checksums.

The .NET runtime is included. Linux packages install declared media/OCR dependencies and require a compatible desktop portal. See [installation instructions and feature coverage](https://github.com/metalshanked/FrameForge/blob/main/docs/CROSS-PLATFORM.md).

## Included

Screen and region capture, an annotation editor, editable projects, automatic clipboard copy, recent-capture deletion with recovery, manual and automatic scrolling, native Mac/Linux recording with optional audio and pause/resume, offline OCR, MP4/GIF conversion, configurable shortcuts, and optional tray/startup integration.

## Testing and limitations

All five architectures passed [native CI](https://github.com/metalshanked/FrameForge/actions/runs/34890935586): 68 shared checks and 3 instance checks per target, 7 native Mac checks per Mac architecture, 9 Linux media checks per Linux architecture, and 118 package checks in total.

The Intel Mac passed installed-app editing, OCR, clipboard, Finder, and full-screen capture checks on the earlier test build. The final build launches, but its updated ad-hoc signature invalidated the previous capture permission; capture/recording must be approved and retested on that exact build. Apple Silicon has native automated coverage, not physical desktop acceptance.

**Mac bundles are ad-hoc signed, not Developer ID signed or notarized.** Downloaded apps may be blocked by Gatekeeper, and installing a new build can require renewed capture permission. Do not disable macOS security protections.

**Linux desktop capture is not fully validated.** WSLg ran UI, instance, and media checks but does not provide the required screen-sharing, pointer-control, or global-shortcut portals in the tested session. Real GNOME/KDE acceptance remains necessary.

Audio synchronization, automatic scrolling, global shortcuts, startup, and mixed-display behavior need further real-desktop testing. This preview is not a claim of complete feature parity or stable cross-platform support. See [the verification report](https://github.com/metalshanked/FrameForge/blob/main/docs/TEST-REPORT-DESKTOP-PREVIEW.md).
